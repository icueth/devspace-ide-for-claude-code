# Built-in Design Packs

Bundled with DevSpace as the default Design Studio assets. See ATTRIBUTION.md and LICENSE.

## Layout
- `skills/<slug>/SKILL.md` — design skill (instructions for "design a X")
- `design-systems/<slug>/DESIGN.md` — brand/style system

Users can override these by creating skills/systems at:
- `~/.claude/skills/<slug>/SKILL.md` (global)
- `<project>/.claude/skills/<slug>/SKILL.md` (per-project)
